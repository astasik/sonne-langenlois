# Sonne Langenlois

PWA mit Live-Sonnenschein der TAWES-Station Langenlois (GeoSphere Austria) und 24-Stunden-Sonnenprognose (Open-Meteo).

Live: https://astasik.github.io/sonne-langenlois/

- Station wird automatisch über den Namen gesucht; per `?station=ID` fix setzbar.
- Daten: GeoSphere Austria TAWES (CC BY 4.0), Open-Meteo.com (CC BY 4.0).
